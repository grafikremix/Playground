# Radley’s AI Playground

Live at [grafikremix.github.io/Playground](https://grafikremix.github.io/Playground/).

A playground of random ideas generated by AI. One prompt per idea, made by me. No do-overs.

The index is a grid of stills. Tap opens the experiment.

Stills are captured from the live experiments (`?still=1` poses them), then cropped and treated. With the site running locally:

```
npm run stills
```

Or `PLAYGROUND_URL=http://127.0.0.1:4173 npm run stills` against a preview build. Output lands in `public/experiments/<slug>/still.{avif,webp,jpg}`.

Ideas live in `src/experiments.js`. Each entry needs `prompt` (the exact wording, unchanged) and `date` (ISO, `YYYY-MM-DD`). To add one: an entry there, `src/specimens/<slug>.js`, `src/pages/<slug>.js`, `specimens/<slug>.html`, then `npm run stills`.

Every idea has synthesized Web Audio for its actions (no samples). Idea pages show a shared Start button first; the tap unlocks audio (a real click) and starts the piece. Nothing animates or takes input until then. Peek on the landing auto-plays muted without Start; stills skip it too. Unlock also retries on `touchstart` / `touchmove` / `touchend` / `pointerup` / `click` (and `keydown`) until the audio context is running, so a first drag or hold works on iPhone. Sound is the haptic fallback there. A Sound On / Sound Off control sits bottom-left on every idea page (default on). Off mutes the master and skips creating voices. The choice persists in `localStorage` and a `playground-sound` cookie (`path=/Playground`, 1 year). Keep it tasteful, low volume, no clipping. Peek and stills stay silent.

GitHub Pages caches HTML for 10 minutes (`max-age=600`). Each build writes `version.json`; pages fetch it `no-store` and reload with a `_b` query if the build id changed, so a stale HTML document picks up the new hashed bundles.

Every idea is always dark Tron / Ice — techno, electric 80s, neon glow lines, near-black backgrounds, grid/vector feel, synthy sound — regardless of the style the prompt asks for.

Animal sounds in `bubbles` are synthesized in the browser (Web Audio). No third-party samples. `cube` is built with three.js.
