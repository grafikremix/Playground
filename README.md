# Radley’s AI Sandbox

Live at [grafikremix.github.io/Playground](https://grafikremix.github.io/Playground/).

A playground of random ideas generated by AI. One prompt per idea, made by me. No do-overs.

The index is a grid of stills. Dithered phosphor until you hover or hold; colour blooms from the press. Tap opens the experiment. Hold does not.

Stills are captured from the live experiments (`?still=1` poses them), then cropped and treated. With the site running locally:

```
npm run stills
```

Or `PLAYGROUND_URL=http://127.0.0.1:4173 npm run stills` against a preview build. Output lands in `public/experiments/<slug>/still.{avif,webp,jpg}`.

Ideas live in `src/experiments.js`. Each entry needs `prompt` (the exact wording, unchanged) and `date` (ISO, `YYYY-MM-DD`). To add one: an entry there, `src/specimens/<slug>.js`, `src/pages/<slug>.js`, `specimens/<slug>.html`, then `npm run stills`.

Animal sounds in `bubbles` are synthesized in the browser (Web Audio). No third-party samples.
